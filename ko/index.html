자체 데이터로 학습한 OCR

자체적으로 마련한 데이터로 인식기를 학습시켰습니다. 한국어 스캔 책에서 BixoPDF의 오류는 주요 PDF 프로그램 A의 약 3분의 1, 프로그램 B의 약 5분의 1이었습니다. 영어 책에서는 둘 중 더 나은 프로그램과 비슷했습니다. 모든 작업이 PC 안에서 이루어지므로 문서가 서버로 전송되지 않습니다.

테스트 방법. 일반 PDF의 페이지에 약간의 기울기·흐림·노이즈·JPEG 압축을 더해 300 dpi 회색조 스캔 이미지로 만들고, 이미지만 있는 PDF로 저장했습니다. 이 파일을 2026년 10월 같은 PC에서 각 프로그램으로 OCR했습니다. 각 결과의 텍스트 레이어를 같은 방법으로 추출해 띄어쓰기를 제외하고 원문과 비교했습니다. 두 책 모두 인식기 학습에는 쓰지 않았습니다. 프로그램 A와 B는 OCR 기능이 있는, 널리 쓰이는 상용 PDF 편집기 두 가지이며, 테스트 PC에 설치된 버전으로 테스트했습니다.

유의 사항. 이 결과는 제한된 환경에서 제한된 문서로 테스트한 것으로, 모든 환경과 문서에서 같은 결과가 나온다는 뜻은 아닙니다. 정확도는 스캔 상태, 레이아웃, 글꼴, 언어, 설정에 따라 달라질 수 있습니다.

책갈피와 목차 링크 자동 생성

1,000페이지짜리 스캔 파일은 원하는 곳으로 쉽게 이동할 수 있어야 쓸모가 있습니다. BixoPDF는 책의 목차 페이지를 읽어 책갈피 트리와 링크를 만들어 줍니다. 사용자는 결과를 확인하고, 불확실하다고 표시된 몇 줄만 고치면 됩니다.

  1. 목차 페이지 지정

    페이지 목록에서 목차 페이지를 선택합니다. 예: 5–12페이지.

  2. 모든 항목 인식

    제목, 번호 체계에 따른 단계, 인쇄된 페이지 번호를 읽습니다. 인쇄된 페이지 번호는 각 페이지 위아래에 찍힌 번호, 책의 페이지 레이블, 또는 페이지 차이를 이용해 PDF 페이지와 맞춘 뒤, 각 페이지의 본문과 대조해 확인합니다. 문단 번호(1.01, 2.30)를 쓰는 책도, OCR로 인식한 목차도 처리합니다. 잘못 인식된 페이지 번호, 머리글, 중복 인식된 글자는 자동으로 정리하고, 제목은 해당 페이지의 표제를 보고 바로잡습니다.

  3. 클릭 몇 번으로 고치기

    불확실한 줄에는 표시가 붙습니다. + 와 − 로 단계를 바꾸고, 페이지 번호를 고치고, 줄을 포함하거나 제외합니다.

  4. 책갈피와 링크 만들기

    목차의 각 줄이 해당 장으로 가는 링크가 됩니다. 링크는 다른 PDF 뷰어에서도 작동하며, 다시 실행하면 링크를 중복으로 만들지 않고 기존 링크를 교체합니다.

스캔에서 텍스트로

OCR 텍스트를 이 앱이나 어떤 PDF 뷰어에서나 선택·복사·검색하고, 텍스트 파일로 내보냅니다.

페이지

페이지 삽입·삭제·이동·회전·자르기·나누기, 그리고 i, ii, 1, 2 같은 페이지 레이블 지정.

합치기

여러 PDF와 이미지를 하나의 파일로 합칩니다. 앱에서도, 탐색기의 마우스 오른쪽 메뉴에서도 할 수 있습니다.

압축

흑백, 회색조, JPEG 품질, 해상도를 조정해 스캔 파일 용량을 줄입니다. 예상 용량을 먼저 보여 줍니다.

여러 파일 검색

폴더 안의 모든 PDF에서 단어나 구절을 찾습니다. 줄바꿈으로 나뉜 곳도 찾고, 해당 페이지를 바로 엽니다.

보호와 내보내기

AES-256 암호 설정, 페이지를 JPG·PNG로 저장, OCR 텍스트 내보내기.

보호된 PDF 안내

암호를 묻기 전에 문서에 어떤 제한(인쇄, 변경, 복사, 주석, 페이지)이 걸려 있는지, 암호 없이 읽을 수 있는지 알려 줍니다.

집중 모드

F11을 누르면 페이지만 남기고 모두 숨겨 책처럼 넘겨 봅니다. 형광펜, 메모, 사전은 그대로 쓸 수 있습니다.

다음 찾기, 이전 찾기

F3과 Shift+F3으로 문서 안의 검색 결과를 하나씩 이동합니다. 확대·축소는 10%씩 조절됩니다.

워터마크

텍스트, 로고, 또는 둘 다를 원하는 색으로 선택한 페이지나 홀수·짝수 페이지에 넣습니다. 아랍어와 힌디어도 Windows에 표시되는 모양 그대로 들어가며, 삭제도 간단합니다.

Word와 Excel

PDF를 글꼴·제목·표를 살린 Word 문서나 Excel 통합 문서로 저장합니다. OCR 텍스트도 포함됩니다.

8개 언어

용량이 큰 스캔 파일 압축

스캔 문서는 용량이 수백 MB에 이르러 메일로 보내기도, 법원이나 고객 포털에 올리기도, 수천 건씩 보관하기도 부담스럽습니다. 압축 정도를 고르고, 적용하기 전에 용량과 페이지 모양을 확인한 뒤, 더 작은 사본으로 저장합니다.

흑백

텍스트 페이지를 선명한 1비트 이미지로 바꿉니다. 용량이 가장 많이 줄어듭니다. 기준값은 자동으로 정하거나 직접 지정합니다.

회색조

흑백 문서를 컬러로 스캔했다면 불필요한 색을 없앱니다.

JPEG 품질

사진과 음영이 있는 페이지를 선택한 품질로 저장합니다.

해상도

72–300 dpi. 화면·메일용은 100–150, 인쇄용은 200–300. 원본보다 높이지는 않습니다.

예외

사진, 표지, 그림이 있는 페이지는 자동으로 색을 유지하며, 건드리지 않을 페이지를 1, 5, 120-130처럼 지정할 수도 있습니다.

먼저 테스트

파일을 저장하기 전에 예상 용량과, 확대해 볼 수 있는 압축 전후 미리 보기를 보여 줍니다.

다른 내용은 그대로. 텍스트, OCR 텍스트, 주석, 책갈피는 그대로 유지됩니다. 페이지 이미지만 다시 압축합니다.

원본은 보존됩니다. 결과는 새 파일로 저장되어 별도 탭에서 열리므로 비교해 볼 수 있습니다.

검색도 그대로. OCR한 책을 압축해도 어떤 PDF 뷰어에서나 검색과 복사가 됩니다.

OCR에 인터넷 연결이 필요한가요?

아닙니다. 인식기가 앱과 함께 설치되어 PC 안에서 실행됩니다. 문서는 어디에도 업로드되지 않습니다.

사전에 인터넷 연결이 필요한가요?

사전 패널에서 언어 팩을 처음 다운로드할 때만 필요합니다. 언어 팩은 무료입니다. 그 뒤로는 모든 검색이 PC 안에서 이루어지고, 찾아본 단어는 전송되지 않습니다. 다운로드에 대해서는 개인정보 처리방침에 설명해 두었습니다.

OCR 중에 다른 작업을 할 수 있나요?

네. OCR은 백그라운드에서 실행되므로, 긴 스캔 파일을 인식하는 동안 다른 PDF를 새 탭으로 열어 읽고, 형광펜과 메모를 넣고, 저장할 수 있습니다. 다만 OCR은 메모리를 많이 사용합니다. 메모리가 넉넉하지 않은 PC에서 OCR 중에 아주 큰 PDF를 열거나 여러 파일을 동시에 OCR하면 앱이 멈출 수 있습니다. 작업을 먼저 저장하고, OCR은 하나가 끝난 뒤 다음 작업을 시작하십시오.

앱은 어떤 언어를 지원하나요?

영어, 한국어, 일본어, 중국어(간체·번체), 러시아어, 힌디어, 아랍어입니다. 처음에는 Windows 언어로 시작하며, 설정 → 언어에서 바꿀 수 있습니다. 아랍어에서는 화면이 오른쪽에서 왼쪽으로 배치됩니다. 앱 언어와 관계없이 OCR은 50개 언어를 인식합니다.

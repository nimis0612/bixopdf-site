책갈피와 차례 링크를 자동으로

1,000쪽짜리 스캔은 원하는 곳으로 쉽게 오갈 수 있어야 쓸모가 있습니다. BixoPDF는 책에 있는 차례 쪽을 읽어 책갈피 트리와 링크를 만들어 줍니다. 이용자는 결과를 살펴보고, 확실하지 않다고 표시된 몇 줄만 고치면 됩니다.

  1. 차례 쪽 지정

    쪽 목록에서 차례 쪽을 고릅니다. 예를 들어 5–12쪽.

  2. 항목을 모두 읽습니다

    제목, 번호 매김으로 정한 단계, 인쇄된 쪽 번호를 읽습니다. 인쇄된 쪽은 각 쪽 위아래에 찍힌 쪽 번호, 책의 쪽 레이블, 또는 쪽 차이로 PDF 쪽과 맞춘 뒤 각 쪽의 글과 대조해 확인합니다. 문단 번호(1.01, 2.30)로 매긴 책도 되고, OCR로 읽은 차례 쪽도 됩니다. 잘못 읽은 쪽 번호, 쪽머리 제목, 겹쳐 읽힌 글자를 알아서 정리하고, 제목은 그 쪽의 표제를 보고 바로잡습니다.

  3. 클릭 몇 번으로 고치기

    미심쩍은 줄에는 표시가 붙습니다. + 와 − 로 단계를 바꾸고, 쪽 번호를 고치고, 줄을 넣거나 뺍니다.

  4. 책갈피와 링크 만들기

    차례의 줄마다 해당 장으로 가는 링크가 됩니다. 링크는 다른 PDF 리더에서도 작동하고, 다시 실행하면 새 링크를 덧쌓지 않고 옛 링크를 바꿉니다.

그리고 날마다 쓰는 도구

스캔에서 글자로

OCR 글자를 이 앱이나 어느 PDF 리더에서나 선택·복사·검색하고, 일반 텍스트로 내보냅니다.

쪽

쪽 넣기·지우기·옮기기·회전·자르기·나누기, 그리고 i, ii, 1, 2 같은 쪽 레이블 지정.

합치기

여러 PDF와 이미지를 파일 하나로 합칩니다. 앱에서도, 탐색기의 오른쪽 클릭 메뉴에서도 됩니다.

압축

흑백, 회색조, JPEG 품질, 해상도로 스캔을 줄입니다. 크기 예상치를 먼저 보여 줍니다.

여러 파일 검색

폴더 안 PDF 전체에서 낱말이나 구절을 찾습니다. 줄바꿈으로 갈라진 곳도 찾고, 그 쪽을 바로 엽니다.

보호와 내보내기

AES-256 암호 걸기, 쪽을 JPG·PNG로 저장, OCR 글자 내보내기.

보호된 PDF 알려 주기

암호를 묻기 전에 문서가 무엇을 막아 두었는지(인쇄, 변경, 복사, 주석, 쪽) 알려 주고, 암호 없이 읽을 수 있는지도 알려 줍니다.

집중 모드

F11을 누르면 쪽만 남기고 모두 숨겨 책처럼 넘겨 봅니다. 형광펜, 메모, 사전은 그대로 쓸 수 있습니다.

다음 찾기, 이전 찾기

F3과 Shift+F3으로 문서 안의 일치 항목을 하나씩 오갑니다. 확대·축소는 10 %씩 움직입니다.

워터마크

글자, 로고, 또는 둘 다를 원하는 색으로 고른 쪽이나 홀수·짝수 쪽에 넣습니다. 아랍어와 힌디어도 Windows가 보여 주는 모양 그대로 들어가고, 지우기도 그만큼 쉽습니다.

Word와 Excel

PDF를 글꼴·제목·표를 살린 Word 문서나 Excel 통합 문서로 저장합니다. OCR 글자도 들어갑니다.

8개 언어

앱 화면을 영어, 한국어, 일본어, 중국어, 러시아어, 힌디어, 아랍어로 쓸 수 있고, 아랍어에서는 오른쪽에서 왼쪽으로 배치됩니다.

큰 스캔 파일을 작게

글자 쪽을 선명한 1비트 이미지로 바꿉니다. 가장 많이 줄어듭니다. 문턱값은 자동으로 정하거나 직접 정합니다.

JPEG 품질

사진과 음영이 있는 쪽을 고른 품질로 저장합니다.

해상도

72–300 dpi. 화면과 메일용은 100–150, 인쇄용은 200–300. 원래보다 키우지는 않습니다.

예외

사진, 표지, 그림이 있는 쪽은 저절로 색을 지키고, 손대지 않을 쪽을 1, 5, 120-130처럼 적어 둘 수도 있습니다.

파일을 쓰기 전에 새 크기 예상치와, 확대해 볼 수 있는 전후 미리 보기를 보여 줍니다.

다른 것은 잃지 않습니다. 글자, OCR 글자, 주석, 책갈피는 그대로입니다. 쪽 이미지만 다시 압축합니다.

원본은 남습니다. 결과는 새 파일로 저장되어 따로 탭에서 열리므로 견주어 볼 수 있습니다.

검색도 그대로. OCR을 거친 책을 압축해도 어느 PDF 리더에서나 검색하고 복사할 수 있습니다.

사기 전에 써 볼 수 있나요?

네. 15일 체험판은 15일 동안 정식판과 똑같이 쓸 수 있습니다. 체험은 PC당 한 번이며, 다시 설치해도 새로 시작되지 않습니다. 그 뒤에는 Microsoft Store에서 정식판을 구입하시면 됩니다.

OCR에 인터넷 연결이 필요한가요?

아닙니다. 인식기는 앱과 함께 설치되어 내 컴퓨터에서 돌아갑니다. 문서는 어디에도 올라가지 않습니다.

사전에 인터넷 연결이 필요한가요?

사전 패널에서 언어 팩을 요청해 한 번 내려받을 때만 필요합니다. 언어 팩은 무료입니다. 그 뒤로는 찾기가 내 PC에서 이루어지고, 찾아본 낱말은 보내지 않습니다. 내려받기에 대해서는 개인정보 처리방침에 설명해 두었습니다.

OCR이 도는 동안 다른 작업을 할 수 있나요?

네. OCR은 백그라운드에서 돌아가므로, 긴 스캔을 인식하는 동안 다른 PDF를 새 탭으로 열어 읽고, 형광펜과 메모를 넣고, 저장할 수 있습니다. 다만 OCR은 메모리를 많이 씁니다. 메모리가 넉넉하지 않은 PC에서 OCR이 도는 중에 아주 큰 PDF를 열거나 여러 파일에 동시에 OCR을 돌리면 앱이 멈출 수 있습니다. 작업을 먼저 저장하고, OCR 작업은 하나가 끝난 뒤 다음을 시작하십시오.

앱은 어떤 언어로 쓸 수 있나요?

영어, 한국어, 일본어, 중국어(간체와 번체), 러시아어, 힌디어, 아랍어입니다. 처음에는 Windows 언어로 시작하고, 설정 → 언어에서 바꿀 수 있습니다. 아랍어에서는 창이 오른쪽에서 왼쪽으로 배치됩니다. 앱 언어와 관계없이 OCR은 50개 언어를 읽습니다.

어떤 Windows 버전을 지원하나요?

64비트 PC의 Windows 10 버전 1809 이상과 Windows 11을 지원합니다.

책갈피와 링크가 다른 PDF 리더에서도 작동하나요?

네. 표준 PDF 책갈피와 링크 주석으로 저장됩니다.

예전 OCR 프로그램이 PDF에 남긴 글자는 어떻게 되나요?

그 글자가 쪽 이미지 아래에 숨어 있으면, 저장할 때 BixoPDF가 새 OCR 글자로 바꿉니다. 그 글자가 쪽에 보이는 내용이면 먼저 물어봅니다.

PDF를 기본으로 이 앱에서 열게 할 수 있나요?

네. Windows 설정 → 앱 → 기본 앱에서 .pdf 파일에 BixoPDF를 고르십시오.

BixoPDF는 Microsoft Store에서 팝니다. 같은 Microsoft 계정으로 로그인한 모든 Windows PC에서 Store가 설치하고 최신 상태로 유지합니다.
